## 2. PROJECT OVERVIEW
The Flower Shop Electronic Store project is an integrated web application designed for displaying and selling flowers and gift arrangements. The platform allows users to browse products, manage their shopping carts, save favorite items to a wishlist, and place orders smoothly, while providing administrators full control over product and order management.
### Technical Stack:
* **Backend Framework:** Django (Python)
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** SQLite / Relational Database
* **Media Management:** Local Media Storage for product images
